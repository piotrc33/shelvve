# Shelvve

A personal book library as an installable PWA: add a book by picking its EPUB file (title, author, year, publisher and
cover are read from it), rate it 1–10 and write down your thoughts. Data stays in the browser (IndexedDB).

App: https://piotrc33.github.io/shelvve/ (open in Chrome on Android, then "Install app").

```
npm run phone      # dev server on the phone over USB (adb)
npm run test:once  # unit tests
npm run build
```
